Подход удобен для ведения конспектов.
Суть метода в создании иерархической структуры bullet-поинтов разного уровня вложенности. 

## Пример
- Outline-метод
	- удобен для ведения конспектов
	- основан на создании иерархической структуры bullet-поинтов
		- вложенный bullet-поинт дополняет/уточняет/опровергает вышестоящий bullet-поинт
	- **Преимущества**
		- логическая организация
			- чёткая структура информации
		- вложенность упрощает поиск деталей, их связей
		- можно записывать коротко, так как весь контекст уже есть в вышестоящих bullet-поинтах
	- **Недостатки**
		- не подходит для неструктурированных материалов
		- ограничивает "линейностью" изложения мыслей
			- невозможно отразить связь одного bullet-поинта с несколькими другими (в отличие, например, от mindmap)
				- не лучший вариант для мозговых штурмов
